在主页面提供一个入口，点击后进入收藏夹模块的页面
# 功能描述
1️⃣ 在线视频收藏夹（手动输入或者json输入）

用户可以创建一个视频收藏条目，包含以下字段：

视频标题（用户输入）

视频页面链接（URL）

视频时长（用户输入或可选自动填）

缩略图来源（可选）

图片 URL（用户输入或解析得到）

或用户自行截图 / 上传的图片

点击收藏条目时：

通过系统浏览器跳转到对应的视频原网站


2️⃣ 缩略图获取（非强制、低风险）

支持以下缩略图来源（按优先级）：

用户手动提供图片 URL

设计原则：

只保存引用信息，不托管第三方图片

加载失败时自动回退为占位图

用户可随时删除/替换缩略图

3️⃣ 基础管理能力

列表 / grid 视图浏览收藏内容

支持：

搜索（标题 / 备注）

简单排序（最近添加 / 最近访问）

支持删除、编辑收藏条目

# 数据与存储策略
所有收藏数据默认仅存储在本地

不做公开展示

不提供分享链接
