# Project Documents

This directory stores long-term project knowledge for AI agents and developers.

`AGENTS.md` is the startup guide.
`documents/` is the on-demand project knowledge base.

AI agents should not read every file in this directory by default.
They should first check this index, then open only the documents relevant to the current task.

## What Should Be Documented

Record information that affects future development, such as:

- business rules or feature behavior
- important product or technical constraints
- Electron, native messaging, MPV, or extension integration rules
- packaging or environment requirements
- testing boundaries and validation expectations
- current-stage limitations that future tasks must respect

Do not record:

- temporary debugging notes
- one-off implementation details
- outdated discussions
- duplicated rules
- content that belongs in code comments
